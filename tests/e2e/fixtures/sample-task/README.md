# Testaufgabe der Browser-Tests

Eigene, frei verwendbare Mini-Aufgabe: Studierende geben `aufgabe.py` mit den
Funktionen `summe`, `ist_primzahl` und `fakultaet` ab.

- `Dockerfile` – Korrektur-Einstellungen, Kommando `python grade.py`
- `grade.py` – bereitgestellte Datei (Verwendung „Einrichtung“), schreibt `/result/results.json`
- `submissions/correct/aufgabe.py` – Musterlösung, 10 von 10 Punkten
- `submissions/wrong/aufgabe.py` – fehlerhaft (`ist_primzahl(1)`, `fakultaet(0)`), 7 von 10 Punkten
